Choose an installation profile with one chart value: `profile: hardened` installs without cluster-wide roles, managed dashboard, node agent or created namespaces, `profile: idp` turns on probing, metrics observation and Pacto delivery, and `pacto_capabilities` and `/api/capabilities` report how the installation runs.
