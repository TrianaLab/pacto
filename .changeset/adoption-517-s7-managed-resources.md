External systems list the managed resources Pacto read for them: Crossplane, ACK, Config Connector and ASO objects the operator lists, Terraform and OpenTofu states (remote ones listed in `controller.terraformStates`, a local file with `pacto fleet --tf-state`) and the cloud inventory once `controller.cloudInventory` names `aws`, `gcp` or `azure` (default `"off"`). Pacto keeps only each resource's type, name, account, region and engine and reads no Secret; a workload that names a resource's connection Secret becomes its consumer through an inferred `connectionSecret` use. Each resource reads through an offering only when a verified, current `ResourceProvisioned` record from the offering's provider names it, and outside contract otherwise; the Overview shows "Resources through offerings", the fleet map badges external systems with resources outside contract and `pacto fleet entities --outside-contract` (MCP `outside_contract`) lists them. `pacto claim --offering` (MCP `offering`, refusal `OfferingInvalid`) records the offering a claimed system is meant to join as display-only metadata. The observed engine is published as `run.pacto.external.engine` on the inferred contract, and a move between engines raises `EXTERNAL_CHANGED`. The external catalog gains an `inventory` key and the ACK, Config Connector and ASO kinds, so the default catalog digest changes. The chart grants `list` only on the catalog's managed-resource kinds the cluster serves at install or upgrade, plus Crossplane XRD composite and claim kinds, and a group served later raises `MANAGED_GROUP_UNREAD` until `helm upgrade`. Repository discovery proposes Terraform backends as `TERRAFORM_BACKEND`. No contract schema field changes.
