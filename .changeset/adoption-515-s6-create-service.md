Create a service from a declared golden path in the dashboard and over MCP. The golden path page's Create service panel plans the service through `POST /api/fleet/services` and publishes `0.1.0`, contract only, through `POST /api/fleet/services/accept`, signed by the person's fresh login with the dashboard's push credential, after a SubjectAccessReview of `create` on the virtual resource `services.pacto.trianalab.io` in the target namespace, named by the service. A default install lets nobody create until the platform team grants it. Infrastructure comes only through the offerings the caller may consume, every value planned and checked against the offering's closed parameter space and tiers, and each refusal carries a stable code, its field, the closest valid value and the `pacto init` and MCP fix. Agents call `pacto_create_service` on the default `/mcp` endpoint with a registry: `dry_run` returns a plan with `intent_digest`, and a write leaves only a `draft-<n>` a person reviews and signs in the dashboard. The handover is a `pacto init --from` command, a zip of the files and an optional `gh repo create` command run with the person's own Git token; Pacto holds no Git token. No contract field or `pactoVersion` changes.
