# Operational graph demo (fleet)

This walkthrough moved to the published guided tour:
<https://pacto.run/latest/examples/demo-tour/>, whose source is
[`docs/examples/demo-tour.md`](../../docs/examples/demo-tour.md).

The tour runs the same commands against the same fixtures — the bundles in
`examples/demo/bundles`, the ingested evidence in
`examples/demo/fleet-targets.yaml` and the traffic in `examples/demo/traces.json`
— and every transcript on it is generated by running them rather than
transcribed. The CLI walkthrough, the agent scenarios and the fleet API notes
that used to live here are all in it.

Nothing changed about how you run any of it: no cluster, registry or running
process is required.
