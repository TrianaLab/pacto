Each consumer gets its own verdict.

  1. Breaking. auth 3.0.0 removes or changes something 2.1.0 offered. pacto diff lists what.
  2. Incompatible. checkout accepts ^2.0.0, and 3.0.0 falls outside it.
  3. Compatible. reporting accepts >=2.0.0 <4.0.0. Check that it does not use what changed.
  4. Unverified. Nothing says where the consumers run, so the command exits 2.
